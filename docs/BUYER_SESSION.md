# Buyer-only virtual home-bar session

Eric selected a $19, 20-minute virtual session for purchasers of the existing $9 ebook. The request code is BARBUYER. Email intake is theboydsbusinessgroup@gmail.com. No Facebook, WhatsApp, Telegram or Calendly integration was created.

The buyer emails their ebook order ID and purchase email privately, plus timezone, preferred times and one question. The operator verifies the correct ebook purchase and eligibility, agrees a time, then arranges payment and sends meeting details privately. One session per qualifying purchase. The session is paid separately from the ebook. Code alone does not prove purchase or apply a payment discount.

Request intake is publicly advertised through the YouTube channel and two existing offer-video descriptions. New videos use the same offer, spoken purchase CTA and final card after this change merges. The code is an offer reference; it is not a created Gumroad/Stripe coupon. No regular reference price exists, so no discount percentage is advertised.

Purchase verification, scheduling and payment arrangement remain manual. No automatic calendar reservation or paid checkout is deployed. Appointment availability is by arrangement because weekly slots and capacity have not been supplied. The operator states both timezones and cancellation/rescheduling terms before collecting payment. Receipts, buyer emails and meeting links stay private. Adults of legal drinking age; consumption is not required.

The private Boyd's Bar OS files config/offers/ebook-buyer-session.json and docs/offers/EBOOK_BUYER_SESSION.md contain operator rules and receipt copy. Customer records never belong in these GitHub files. The separate Digital Asset Licensing business remains outside this consultation workflow.
