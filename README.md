# Media CDN (December holiday push)

Public social-post assets served to Buffer and Pinterest through jsDelivr. No code runs from here.

holiday-push-2026-dec/: 24 decks (k09-k32) for the Holiday Cocktail Party Menu Kit, one per night Dec 8-31 at 20:41-20:47 CT. Per deck: slides (TikTok carousel), reel (Instagram, Facebook, YouTube Shorts) and a Pinterest pin. Generator: src/ (run from media-cdn holiday-push-2026/src with the kit cover in src/src/).

Kept on its own branch so each jsDelivr package stays under the size limit.
