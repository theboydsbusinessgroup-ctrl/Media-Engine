# JARVIS Integration

JARVIS has the same portfolio-level telemetry access pattern as the other connected systems.

## Allowed
- health and availability summaries
- production/publishing counts
- platform performance summaries
- monetization eligibility/status
- revenue and cost aggregates
- exception counts
- human-review queue counts
- last successful run

## Not allowed through this adapter
- platform credentials or tokens
- raw customer/creator PII
- private content not explicitly approved for telemetry
- direct publication commands
- deletion/edit commands
- payment/payout instructions
- unrestricted spending
- bypassing Media Engine safety, rights, quality, or authority gates

The Media Engine remains operationally independent if JARVIS is unavailable.
